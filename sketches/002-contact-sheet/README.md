## Variant: Contact Sheet

### Design stance
Das Produkt zeigen, nicht die Kategorie: ein Kontaktabzug-Grid (Contact Sheet), eine Zelle ist das erzeugte Thumbnail.

### Key choices
- Motiv: 2×2-Thumbnail-Grid, aktive Zelle in Gruvbox-Orange (#FE8019) mit Play
- Farbe: Gruvbox Light Hard (#fbf1c7) — identische Palette wie dein Zed-Theme
- Formen: großzügige Rundungen, dünne Linien fallen bei 32 px noch nicht raus (14 px Stroke)

### Trade-offs
- Stark: erzählt exakt die App-Funktion; helle Icons heben sich im dunklen Dock ab; persönlich (Gruvbox)
- Schwach: bei 32 px wird das Grid diffus; „Grid“ könnte auch Galerie/Bildbrowser bedeuten

### Best for
Funktion zuerst + persönliche Handschrift (dein Farbsystem).
