## Variant: Frame-Grab gerade

### Design stance
Idee von 003 im Stil des aktuellen App-Icons: Der Frame wird senkrecht aus einem großen, gestrichelten Slot im Filmstreifen nach oben gezogen, eine orange Spur zeigt die Bewegung.

### Key choices
- Hintergrund, Filmstreifen, Perforation und Sonnenuntergang wie im aktuellen Icon (resources/icon.svg)
- Leerer Slot gestrichelt in Orange (#ff9a5a), Bewegungsspur als Verlauf zwischen Slot und Frame
- Frame gerade, mit weißem Rand und Schatten

### Trade-offs
- Stark: Vorgang „herausziehen“ sofort klar, nah am aktuellen Icon
- Schwach: Strichelung und Spur gehen bei 32 px verloren, der Slot wird dort zum dunklen Block

### Best for
Wenn das Icon die Funktion erzählen soll, ohne den bisherigen Look aufzugeben.
