## Variant: Frame-Grab

### Design stance
Der Vorgang als Miniatur: ein Bildframe wird aus der Video-Timeline „herausgezogen“ — der leere gelbe Slot unten zeigt, woher er kommt.

### Key choices
- Motiv: gekippter Foto-Frame (gelber Rand, Sonne + Berge) über einer Timeline mit Lücke
- Farbe: Gruvbox Dark (#32302f→#1d2021), Akzente Gelb (#FABD2F) und Aqua-Grün (#8EC07C)
- Formen: zwei Ebenen (Frame/Timeline) erzählen eine Geschichte; Kippung gibt Dynamik

### Trade-offs
- Stark: einzigartig, erzählt die Funktion als Geschichte, dein Dark-Setup
- Schwach: die Erzählung braucht etwas größere Darstellung; bei 32 px verkommt die Timeline zur Linie

### Best for
Eigenbrötlerische Identität mit klarer Funktionserzählung für Kenner.
